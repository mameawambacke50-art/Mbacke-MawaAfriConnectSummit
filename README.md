# Description du projet

AfriConnect Summit 2026 est un site web vitrine créé pour présenter
une conférence technologique panafricaine fictive.

L'événement rassemble des développeurs, entrepreneurs, investisseurs,
designers et passionnés de technologie autour de plusieurs thématiques
liées à l'innovation africaine.

Le site a été conçu pour être moderne, responsive, fluide et accessible
sur ordinateur, tablette et téléphone.

---

##  Pages du site

Le site comporte quatre pages principales :

- Accueil : présentation de l'événement, chiffres clés,
  intervenants et sponsors.
- Programme : présentation du programme des trois jours.
- Intervenants : présentation et filtrage des intervenants.
- Contact : formulaire d'inscription, FAQ et informations de contact.

---

#Fonctionnalités JavaScript

Le site comprend plusieurs fonctionnalités interactives :

-  Mode sombre / mode clair
-  Compte à rebours
-  Menu hamburger sur mobile
-  Animation des compteurs
-  Animations au défilement
-  Onglets des trois jours du programme
-  Filtrage des intervenants par thématique
-  Validation du formulaire d'inscription
- ⬆ Bouton retour en haut
-  Année dynamique dans le footer
-  Sauvegarde du thème avec `localStorage`
